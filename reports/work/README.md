# Work reports

One file per report, written by [`skills/work-report/`](../../skills/work-report/) from what GitHub
recorded for one repo over a period: merged pull requests and who made,
reviewed and approved them, what the loop built, releases, GitHub milestones,
the specs closed issues name, and the repo's CHANGELOG. Reports are gitignored, so they stay here on the
machine that wrote them; only this README is tracked. The person who asked for
one reads it and sends it.

They name people by GitHub login, with pull request titles and addresses.
