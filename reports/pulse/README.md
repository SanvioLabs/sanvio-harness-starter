# Pulse summaries

One file per summary, named `<since>-to-<until>.md`, written by [`skills/pulse/`](../../skills/pulse/) from
the team's answers in the shared folder over one period. Summaries are gitignored,
so they stay here on the machine that wrote them; only this README is tracked. The
person who asked for one reads it and sends it.

They count people and never name a login, but they quote Other answers as written,
so on a small team an Other answer can identify the person who wrote it.
